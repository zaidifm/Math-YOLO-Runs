# Math YOLO Runs

Research workspace for long-horizon mathematical exploration, reconstruction, verification, and provenance auditing.

## Projects

- [`Jacobian-Conjecture/`](Jacobian-Conjecture/) — post-disproof reconstruction and audit of the July 2026 Jacobian counterexample, with special focus on the BLIND-session boundary/intersection ring, degree filtration, degree-17 canonical-potential minimality, and finite-jet formulation.

## Repository policy

This repository is public. Commit reproducible mathematics, research notes, scripts, public-source references, and publication-safe provenance metadata. Do **not** commit raw private ChatGPT exports, credentials, cookies, browser profiles, or third-party source files whose redistribution status has not been checked.

Exploratory claims are not promoted to established mathematics merely because they are committed here. Each project should distinguish supplied, derived, computed, verified, conjectured, and broken claims, and preserve enough artifacts for independent replay.
